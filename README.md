# 🛍️ Shopix – Full Stack E-Commerce Platform

**Shopix** is a modern full-stack e-commerce web application designed to provide a smooth and convenient online shopping experience. It combines a responsive React frontend with a powerful Node.js and Express backend.

The project focuses on essential e-commerce functionalities, secure authentication, product management, and a scalable application architecture.

🌐 **Live Demo:** https://shopix-drab.vercel.app/

📂 **GitHub Repository:** https://github.com/Aditi-2909/Shopix & https://github.com/Atanu-18/Shopix
---

## ✨ Features

- 🛒 **E-Commerce Experience** – Modern shopping interface.
- 🔐 **User Authentication** – Secure authentication using JWT and Bcrypt.
- 📦 **Product Management** – Backend support for managing product data.
- 💳 **Payment Integration** – Razorpay payment gateway dependency.
- ☁️ **Cloud Image Storage** – Cloudinary integration for image management.
- 📧 **Email Functionality** – Nodemailer integration.
- ⚡ **State Management** – Redux Toolkit for managing application state.
- 📱 **Responsive UI** – Built with React and Tailwind CSS.
- 🚀 **REST API** – Backend APIs powered by Express.js.

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Redux Toolkit
- React Router DOM
- Axios
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)
- Bcrypt
- Multer
- Cloudinary
- Nodemailer
- Razorpay


## 🔑 Environment Configuration

Configure the following services and credentials as required by the backend:

- MongoDB connection string
- JWT secret key
- Cloudinary credentials
- Razorpay API credentials
- Email service credentials
- Frontend/backend API URL


## 🚀 Deployment

The frontend is deployed on Vercel.

## 🎯 Project Objective

The main objective of Shopix is to develop a full-stack e-commerce application while gaining practical experience in modern frontend development, backend API development, database integration, authentication, and third-party service integration.
